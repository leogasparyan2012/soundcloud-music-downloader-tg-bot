# 🎧 SoundCloud → Telegram

Телеграм-бот: присылаешь ссылку на трек, плейлист или альбом SoundCloud — получаешь готовый **MP3 с обложкой, названием и исполнителем**.

## Возможности

- треки, плейлисты и альбомы SoundCloud (включая короткие ссылки `on.soundcloud.com`);
- до 500 треков из одного плейлиста;
- команда `/stop`: текущий трек докачивается и отправляется, остальные не качаются;
- MP3 с обложкой и ID3-тегами (название, исполнитель, ссылка на источник);
- прогресс загрузки прямо в сообщении;
- очередь и лимит одновременных загрузок — бот не захлёбывается при наплыве;
- понятные ошибки: приватный трек, удалённый трек, слишком большой файл, блокировка по региону;
- Docker и docker-compose для запуска на сервере;
- поддержка cookies для приватных треков и прокси для загрузки.

## Как это работает

```
Telegram → aiogram → yt-dlp (качает лучшее аудио SoundCloud) → ffmpeg (MP3 + обложка + теги) → sendAudio
```

Ссылки проверяются по белому списку доменов SoundCloud, поэтому бот не полезет качать что попало. Временные файлы удаляются сразу после отправки, а «осиротевшие» папки от прошлых падений подчищаются при старте.

## Быстрый старт

### 1. Токен бота

Открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username → скопируй токен вида `123456789:AAH...`.

### 2. ffmpeg

Без него нельзя собрать MP3 и вшить обложку.

```bash
# Ubuntu / Debian
sudo apt install ffmpeg

# macOS
brew install ffmpeg

# Windows (PowerShell)
winget install Gyan.FFmpeg
```

Проверка: `ffmpeg -version`.

### 3. Зависимости

Нужен Python 3.11+.

```bash
cd soundcloud-bot   # папка с проектом
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 4. Настройка

```bash
cp .env.example .env
```

Открой `.env` и вставь токен:

```dotenv
BOT_TOKEN=123456789:AAH...
```

Остальные параметры можно не трогать — они уже с разумными значениями.

### 5. Запуск

```bash
python bot.py
```

В логе появится `Бот @your_bot запущен`. Открой бота в Telegram, нажми «Start» и пришли ссылку:

```
https://soundcloud.com/forss/flickermood
```

## Docker

```bash
cp .env.example .env
nano .env                       # вставить BOT_TOKEN
docker compose up -d --build
docker compose logs -f
```

Остановить: `docker compose down`. Обновить после изменений: `docker compose up -d --build`.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и краткая справка |
| `/help` | Как пользоваться ботом |
| `/stop` | Остановить загрузку плейлиста: трек, который уже качается, докачается и отправится, следующие качаться не будут |

## Настройки

Все параметры читаются из `.env` (или переменных окружения — они приоритетнее).

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather. **Обязателен** |
| `DOWNLOAD_DIR` | `downloads` | Папка для временных файлов |
| `AUDIO_QUALITY` | `320` | Битрейт MP3: `128`, `192`, `256`, `320` |
| `MAX_FILE_MB` | `50` | Лимит размера файла, МБ |
| `MAX_PLAYLIST_ITEMS` | `500` | Сколько треков качать из плейлиста (1–500) |
| `MAX_CONCURRENT_DOWNLOADS` | `2` | Одновременных загрузок (1–10) |
| `DOWNLOAD_TIMEOUT` | `900` | Таймаут одной загрузки, секунды |
| `COOKIES_FILE` | — | `cookies.txt` для приватных треков |
| `PROXY` | — | Прокси для загрузки, напр. `http://user:pass@host:8080` |
| `TELEGRAM_API_URL` | — | Адрес локального Bot API server |
| `LOG_LEVEL` | `INFO` | `DEBUG`, `INFO`, `WARNING`, `ERROR` |

## Ограничения и честные оговорки

**50 МБ.** Облачный Telegram Bot API не принимает файлы больше 50 МБ — это примерно 20 минут MP3 в 320 кбит/с. Бот проверяет размер до отправки и присылает ссылку, если файл не влезает. Лимит можно поднять только вместе с собственным [локальным Bot API server](https://github.com/tdlib/telegram-bot-api): запусти его с флагом `--local`, укажи `TELEGRAM_API_URL=http://127.0.0.1:8081` и `MAX_FILE_MB=2000`.

**Качество.** SoundCloud чаще всего отдаёт 128 кбит/с MP3 (иногда AAC 256 через HLS). Перекодирование в 320 кбит/с **не улучшает** звук — только увеличивает файл. Если важен размер, поставь `AUDIO_QUALITY=128`.

**Приватные треки.** SoundCloud не отдаст их без авторизации. Можно экспортировать cookies браузера (расширение «Get cookies.txt LOCALLY»), сохранить файл как `cookies.txt` рядом с ботом и указать `COOKIES_FILE=cookies.txt`. Cookies дают доступ к аккаунту — используй отдельный аккаунт и не коммить файл в git.

**DRM.** Часть треков SoundCloud защищена DRM: сервис не отдаёт для них аудиопоток, поэтому yt-dlp (а значит, и бот) не может их скачать. Бот сообщит об этом и продолжит плейлист. Обойти DRM-защиту нельзя.

**Регион.** Если трек заблокирован в стране сервера, поможет `PROXY`.

**Права.** Бот — инструмент. Скачивай только тот контент, на который у тебя есть права, и соблюдай условия SoundCloud.

**Актуальность yt-dlp.** SoundCloud периодически меняет API. Если перестало работать — сначала обнови yt-dlp:

```bash
pip install -U yt-dlp
```

## Структура проекта

```
.
├── bot.py                  # точка входа: настройка, polling, graceful shutdown
├── soundcloud_bot/
│   ├── config.py           # чтение и валидация .env
│   ├── downloader.py       # yt-dlp + ffmpeg: метаданные, MP3, обложка, теги
│   ├── handlers.py         # команды, ссылки, прогресс, отправка аудио
│   └── utils.py            # разбор ссылок, имена файлов, форматирование
├── tests/                  # pytest: ссылки, имена файлов, конфиг
├── Dockerfile
├── docker-compose.yml
├── requirements.txt
└── .env.example
```

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты не ходят в сеть и не требуют токена: проверяются разбор ссылок, имена файлов, форматирование, валидация конфига, тексты ошибок, сценарии обработчика с фейковым Telegram и команда `/stop` (текущий трек отправляется, остальные не качаются).

## Частые проблемы

| Симптом | Решение |
|---|---|
| `Не задан BOT_TOKEN` | Скопируй `.env.example` в `.env` и вставь токен |
| `ffmpeg не найден в PATH` | Установи ffmpeg (см. выше) и перезапусти бота |
| `Telegram отклонил BOT_TOKEN` | Токен отозван или скопирован не полностью — получи новый у @BotFather |
| `Не удалось скачать трек: ...` | Обнови yt-dlp, проверь ссылку, при необходимости настрой cookies/прокси |
| `This video is DRM protected` | Трек защищён DRM — SoundCloud не отдаёт его для скачивания, скачать нельзя; бот пропустит его и продолжит плейлист |
| Бот не реагирует на ссылки в группе | У бота включён privacy mode: отключи его через `/setprivacy` у @BotFather или сделай бота админом группы |
| `Файл слишком большой` | Трек длиннее лимита 50 МБ — используй локальный Bot API или скачай вручную |
